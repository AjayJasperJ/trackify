## Trackify iOS Crash Investigation

### Problem
- Flutter app "trackify" crashes immediately on iOS device launch
- App builds fine in GitHub Actions but crashes on device
- No Mac available for development/debugging

### Root Cause Found
- `Payload/Runner.app/Runner` missing execute permission (`0o644` instead of executable)
- Also affects framework binaries in `Frameworks/` directory
- iOS launchd fails with: `spawn failed, error=85: Bad executable (or shared library)`
- This happens because `flutter build ios --no-codesign` + manual `cp -r` into IPA strips execute bits

### Fix Applied
- Updated `.github/workflows/build-apk-ipa.yml` to add before zipping:
  - `chmod +x build/ios/ipa/Payload/Runner.app/Runner`
  - `find build/ios/ipa/Payload/Runner.app/Frameworks -type f -exec chmod +x {} +`
- Generated local test IPA: `/workspace/trackify-unsigned-execfix.ipa`

### User Constraints
- Ubuntu-only environment (no Mac)
- Building via GitHub Actions (macOS runner)
- Installing via AltStore/sideload
- Cannot extract device crash logs without root/libimobiledevice

### Key Files
- `/workspace/.github/workflows/build-apk-ipa.yml` - patched
